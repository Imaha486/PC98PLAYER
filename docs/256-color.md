# BIOS ROM不要の256色グラフィック

## 有効化

`PC98PLAYER.INI` の `[PC98PLAYER]` に `VideoColors=256` を指定します。省略時・16指定時・不正な値では従来の16色機として動きます。

```ini
[PC98PLAYER]
Start=GAME98.BAT
VideoColors=256
```

この設定は対応能力の指定です。起動直後は従来モードで、ゲーム付属のドライバーが要求した時だけ256色へ切り替えます。16色のソフトを強制的に256色へ変換する機能ではありません。

## 実装範囲

- 512 KiBのPEGC VRAM、2本の32 KiBバンク窓、256エントリーのRGBパレット、表示・描画ページ。
- 640×400／640×480のpacked pixel表示と、基本的なplanar転送、ラッチ、ビット／プレーンマスク、ROP。
- 従来のテキスト合成を共用。ゲーム付属ドライバーによるI/O切替に加え、INT 18h AH=4Dh（CH=0: 従来／1: 256色）を既存HLEへ接続。
- 本家のPEGC／VRAMのスナップショット形式を維持し、追加のplanarラッチはPGCXチャンクに分離。拡張なしの旧状態・本家のPEGC状態・このPRの旧PEGC状態も読み込めます。

BIOS ROM、他のエミュレーターの実装、ゲームバイナリの修正は含めません。既存のHLE・メモリ／I/O層へ独立に追加しています。ハードウェアの公開資料: https://www.satotomi.com/sl9821/sl9821_tec5.html 。AH=4Dhの利用は配布版AGS_9821ドライバーの実際の呼び出しと動作で確認しました。

高位アドレスのリニアフレームバッファ、高度な32ビットplanarシフト／転送、INT 18h AH=30h/31hのタイミング・解像度サービスは未対応です。完全なPC-9821の再現ではありません。

## 検証（2026-10-26）

本家 `2c27c8a` を基に本PRを適用した共通コアをmacOSでネイティブ実行しました。アリスソフト配布データは一時フォルダーへコピーし、入力付きで以下まで確認しています。ゲームデータ・画像・セーブファイルはPRに含みません。

| タイトル | 起動設定 | 確認範囲 |
|---|---|---|
| Rance IV | 256色対応有効 | PEGCが有効となり、序盤のゲーム画面・会話を表示（4,200フレーム） |
| ランス4.1 | 256色対応有効 | ロゴ後の縦縞を解消、工場の会話画面まで進行（4,200フレーム） |
| ランス4.2 | 256色対応有効 | ロゴ後の縦縞を解消、序盤の会話画面まで進行（4,200フレーム） |
| 闘神都市II | 256色対応有効 | ソフトは従来の16色経路を選択し、主人公の名前選択画面へ進行（4,200フレーム） |
| AmbivalenZ | 256色対応有効 | PEGCが有効となり、導入文の先のカラーCG・会話を表示（18,000フレーム） |

本家の16色のみの動作と区別し、特に4.1/4.2で必要なAH=4Dhを追加しています。これは起動から序盤の確認であり、全編クリアやWindows実機でのゲームプレイを保証するものではありません。

## 回帰テスト

ゲームやBIOS ROMを使わない合成テストです。

```sh
cmake -S tests -B build/graphics-tests
cmake --build build/graphics-tests --config Release
ctest --test-dir build/graphics-tests -C Release --output-on-failure
```

INIの既定値、HLEによるモード切替とpixel/palette描画、不正なモード値、256色、バンク境界、表示ページ、planarマスク／ROP、状態の往復・旧形式、16色機での分離を確認します。GitHub ActionsではWindows x64のアプリビルドと同テストを実行します。アプリ本体のVisual Studioプロジェクトにも `core/pegc.cpp` を登録しています。

## 2026-11-02 本家更新との統合

本家 `f75c176` のPEGC実装を基に統合しました。本家の400／480ライン描画、GDCのSCROLL／PITCH、1画面／2画面、追加音源・ドライバーは維持し、AH=4Dh・planar ROP／マスク・設定分離を追加しています。`core/video.cpp` は本家と同一です。本家の256色CDデモ用INIにも `VideoColors=256` を明記しました。

回帰テストには31kHz／480行、2.5MHz・5MHzの行幅、分割スクロール、本家と旧PRのスナップショット互換性を追加しました。
