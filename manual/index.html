PC98PLAYER

PC-9801 のゲームを、Windows の上でそのまま遊ぶための小さな仮想 PC-98 です。

PC98PLAYER とは

PC98PLAYER は、PC-9801 の本体・BIOS・MS-DOS の働きを自前で用意した小さな仮想 PC-98 です。 実機の ROM や MS-DOS 本体は必要ありません。ハードディスクにインストールした状態のゲームのフォルダに PC98PLAYER.EXE を置くだけで動きます。

  • 画面: テキスト画面・16 色グラフィック・GRCG・EGC・200 ライン表示
  • 音: FM 音源（PC-9801-86 / 26K 相当）、86 ボードの PCM、ビープ、MIDI（任意）
  • 文字: 漢字 ROM の代わりに、Windows の MS ゴシックから字形を作ります（外字にも対応）
  • 入力: キーボード、マウス（バスマウス／マウスドライバ相当）、ゲームパッド（音源ボードのジョイスティック端子として。ボタンにキーも割り当て可）
  • いつでも保存・再開できるステートセーブ
  • ゲームの用意を手伝うインストールアシスタント

動作環境: Windows 10 / 11（64bit）。

どの章を読めばいいか

手元にあるゲームの形によって、読む章が変わります。

第一章

基本的な使い方

ハードディスクにインストール済みのゲームのフォルダがある。フォルダに PC98PLAYER.EXE を入れて起動する、いちばん基本の遊び方（フリーソフト Super Depth で実際に遊んでみるチュートリアル）と、設定（INI）の一覧。
第二章

HDI イメージの利用

ゲームがハードディスクイメージ（HDI・NHD・THD）で手元にある。インストールアシスタントで中身をフォルダへ展開し、INI を作って遊ぶ。
第三章

FDI イメージの利用

フロッピーのイメージ（FDI・D88・NFD など）や本物のフロッピーディスクしかない。インストールアシスタントでインストーラを動かし、フォルダへインストールする。MS-DOS を使わずフロッピーから直接起動する初期のゲームも、ここで。
第四章

トラブルシューティング集

すぐ閉じる・落ちる・音が出ない・キーディスクを求められる・インストールがうまくいかない、などの症状別の対処と、不具合の報告のしかた。
第五章

メモリエディタ

ゲームのメモリを見て直接書き換える別窓。値の変化で番地を絞り込むサーチ、コマンドでの書き込み、書き込みをまとめて実行するコードエディタ付き（上級者向け）。

インストールアシスタント

「ゲームのフォルダ」を用意するための次の 3 つの機能を、まとめてインストールアシスタントと呼びます。どれも、イメージやドライブを PC98PLAYER.EXE にドロップするだけで始まります。

ドロップするものインストールアシスタントがすること説明
ハードディスクイメージ（.HDI など）中身をフォルダへ展開し、起動するファイルを選んで INI を作る第二章
フロッピーイメージ（.FDI・.D88 など。何枚でも）イメージをまとめてセットし、インストーラを動かす第三章
フロッピードライブ（USB フロッピーの A:\ など）本物のディスクからインストーラを動かす（ディスクの入れ替えは実物で）第三章

よく使うキー

キーはたらき
Shift+F11 / F11ステートセーブ／ステートロード（フロッピーの入れ替えもこの画面）
ウインドウをクリック / F12マウスを捕まえる / 放す
Shift+F12（押している間）早送り
Alt+Enter全画面表示の切り替え
F11 → RINI を読み直してプログラム再起動（INI の動作確認に）
F11 → S画面＆サウンド設定（音源・MIDI・音量・画面を画面で直して INI に保存）

キーの一覧は第一章の「操作方法」にあります。
