第三章

FDI イメージの利用

フロッピーのイメージをまとめてセットしたり、本物のフロッピードライブを使ったりして、インストールアシスタントでゲームのインストーラを動かすスタイルです。

3-1. 考え方

フロッピー版のゲームは、実機と同じようにゲーム付属のインストーラでハードディスクへインストールしてから遊びます。 インストールアシスタントは、フロッピー（イメージまたは本物）とインストール先のフォルダ（ハードディスク）を用意して、インストーラを動かすところまでを手伝います。

ドロップFDI（何枚でも）またはフロッピードライブ
→
アシスタントインストーラ・引数・ドライブ名を選ぶ
→
インストールゲーム付属のインストーラが動く
→
INI起動するファイルを選んで作り、そのまま遊ぶ
MS-DOS のファイルが入っていない独自形式のディスク（PC-98 初期の、フロッピーから直接起動するゲーム）は、インストールせずにそのまま起動します（3-11）。
インストールアシスタントの画面から始めたときは、インストールが終わるまで PC98PLAYER.INI を作りません（インストール先に INI があれば、音などの設定だけ借ります）。

3-2. 使えるイメージ・展開先

  • イメージ: FDI（Anex86）、D88（.D88 .D68 .88D .D98）、NFD（T98-Next の r0・r1）、ヘッダ無しのベタ（.HDM .XDF .DUP .TFD .2HD .IMG など）、フラックスイメージ（.SCP・.HFE）。形式の違うものを混ぜても構いません。
  • インストール先: PC98PLAYER を起動したときの作業フォルダー（カレントフォルダ）です。作業フォルダーが Windows のフォルダの中やドライブの直下のときは、1 枚目のイメージの横にイメージと同じ名前のフォルダ（DISK1.FDI なら DISK1）を作ってそこへインストールします。インストール先は画面の左下に表示されます。
ヒント: インストール先を決めておきたいときは、第二章 2-3と同じく、作業フォルダーを指定したショートカットのリンク先の後ろにイメージを並べて書きます。

3-3. インストールアシスタントの画面

フロッピーイメージを PC98PLAYER.EXE にドロップすると（第 1 引数がフロッピーイメージのとき）、次の画面になります。

場所はたらき
タイトル中身を表示しているイメージの名前と「何枚目か」。右上の ◀ ▶ で、中身を見るディスクを切り替えます。
左: フロッピーの中身フォルダ（[名前]）はクリックで開き、ファイルはクリックでインストーラに選びます。BAT・EXE・COM は白で表示。ダブルクリックでそのまま実行。最初は INSTALL.BAT などインストーラらしいファイルが選ばれています。ホイールで一覧を送れます。
右上: 中身選んだ BAT やテキスト（README など）の先頭の行。インストーラがどんな引数（%1 など）を待っているかの手がかりになります。実行ファイルは大きさを表示します。
引数インストーラに渡す引数。クリックして入力します（Tab キーでも切り替え）。例: B:
フロッピー / ハードディスクそれぞれのドライブ名（A〜F）。ハードディスク＝インストール先のフォルダです。同じ文字を選ぶと入れ替わります。
カレント始めるときのカレントドライブ（フロッピーかハードディスクか）。
書き込み禁止「する」（既定）で、フロッピーを書き込み禁止（ライトプロテクト）にして見せます。「ゲームディスクをライトプロテクト状態にして下さい」と確かめるインストーラ（下級生など）があるためです。インストーラがフロッピーへ書き込む必要があるときは「しない」にします。本物のドライブでは「つまみのまま」（ディスクのつまみに従う）になります。
左下インストール先のフォルダと、実際に実行するコマンド（例: A:\INSTALL.BAT B:（カレント A:））。
実行（Enter）/ やめる（Esc）インストーラを動かす / 何もせずに終わる。
引数とドライブ名の決め方: 右上の中身を読んで、インストーラの説明に合わせます。多いのは次の 2 通りです。
  • 「INSTALL インストール先」の形（図 3-1 の %1）→ 引数にハードディスクのドライブ名（B: など）、カレントはフロッピー。
  • 「今いるドライブへ写す。引数は転送元」の形 → 引数にフロッピーのドライブ名、カレントはハードディスク。
メニューを出して選ばせるインストーラなら、引数は空のままで構いません。

3-4. インストールしてみる（例）

  1. DISK1.FDI と DISK2.FDI を選んで、まとめて PC98PLAYER.EXE にドロップします。
  2. 左の一覧で INSTALL.BAT が選ばれていることを確かめます。右上に MD %1\SAMPLE のような行が見えるので、引数にはインストール先のドライブを渡せばよいとわかります。
  3. 引数に B:、フロッピー A、ハードディスク B、カレントは「フロッピー」にして、「実行」を押します。
  4. インストーラが動きます。ディスクの入れ替えを求められたら、次の節のとおり入れ替えてからキーを押します。

3-5. 複数枚のディスクと入れ替え

何枚かをまとめてドロップすると、名前順（DISK1、DISK2 …）に並べて、1 枚目を入れた状態から始めます。 インストーラが「ディスク 2 を入れてください」と言ったら、F11 を押して、下の「フロッピー」の欄で入れ替えます。

キー / ボタンはたらき
N / 「N: 次」次のディスクへ入れ替えます。
P / 「P: 前」前のディスクへ入れ替えます。
F / 「F: 入れる／実機…」メニューから何枚目かを選んで入れたり、別のイメージ・本物のドライブを選んだりします。
E / 「E: 取り出す」ディスクを取り出します。

入れ替えたら Esc で F11 の画面を閉じ、インストーラの指示どおりキーを押して続けます。

3-6. インストールが終わったら

インストーラ（バッチ）が終わると、インストールアシスタントが次のように聞いてきます。

  1. 「ゲームを起動するファイルを選んで PC98PLAYER.INI を作りますか？」 → 「はい」で、インストール先のフォルダを開いたファイル選択が出ます。ゲームを起動するファイルを選んでください。
  2. Start=（選んだファイル）と Drive=（インストールのときのハードディスクのドライブ名）を書いた INI を作り、「続けてゲームを起動しますか？」と聞きます。
  3. 「はい」で、インストール先のフォルダの PC98PLAYER を起動し直して、ゲームが始まります。
  • 最初の質問で「いいえ」を選ぶと、INI は作らずに画面をそのまま残します（インストーラのメッセージを読みたいときなど）。
  • インストール先に既に INI があるときは、「このフォルダの PC98PLAYER.INI でゲームを起動しますか？」とだけ聞きます。
  • Drive= を書くのは、インストーラがドライブ名（B: など）をゲームの設定ファイルに書き込むことがあるためです。インストールのときと同じドライブ名で遊べるようにしています。

次からは、インストール先のフォルダで第一章のとおり起動してください。

3-7. フロッピードライブからインストールする

イメージを作らなくても、ゲームのディスクを入れた本物のフロッピードライブ（USB フロッピーなど）から、そのままインストールできます。

  1. ゲームの 1 枚目のディスクをドライブに入れます。
  2. エクスプローラーで、そのドライブ（例: 「フロッピー ディスク ドライブ (A:)」）を PC98PLAYER.EXE にドロップします（第 1 引数に A:\ を渡すのと同じ。FDD:A や、Greaseweazle の GW でも構いません）。
  3. 図 3-1 と同じインストールアシスタントの画面になります。ここからは 3-4 と同じです。
  4. ディスクの入れ替えを求められたら、本物のドライブでディスクを入れ替えて、インストーラの指示どおりキーを押すだけです。
  • 入れ替えは自動で気づきます: しばらく（1.5 秒ほど）ディスクを触っていなかった後に読むとき、トラック 0 を読み直して中身が替わっていれば、自動で読み直します（F11 の画面の「読み直す」は要りません）。
  • 書き込み禁止: 本物のドライブでは「つまみのまま」が選べます。ディスクの書き込み禁止のつまみに従います。
  • インストール先: 作業フォルダーが Windows のフォルダの中やドライブの直下のときは、PC98PLAYER.EXE の横の PC98GAME フォルダになります。
注意: トラックを初めて読むとき、USB フロッピーは 1 トラック 0.3 秒ほど待ちます（ゲームが止まったように見えます）。PC-98 の 1.25MB のディスクを読むには、3 モード対応のドライブが必要です。プロテクトつきのディスクは USB フロッピーでは読めないことがあります（3-10）。

3-8. 本物のドライブの詳細（USB フロッピー・Greaseweazle）

本物のフロッピードライブは、インストールだけでなく、遊ぶときの仮想フロッピー（キーディスクなど）にも使えます。ディスクの中身は使うときにその場で読みます。

USB フロッピードライブGreaseweazle ＋ PC 用の FDD
読み方Windows のドライバ経由で「セクタ番号」で読む磁気信号（フラックス）をそのまま読み、PC98PLAYER が自分で復調する
普通のディスク（ファイルの読み書き・インストール）○（書き込みも可）○（読み込みのみ）
プロテクトつきの正規ディスク（キーディスクの確認）×（ID のずれたセクタ・CRC エラー等を扱えない）○（隠れたセクタ・CRC エラー・読むたびに変わるセクタ等もそのまま）
PC-98 の 1.25MB（2HD）3 モード対応のドライブだけ3.5 インチ・5 インチの 2HD ドライブ（回転数の違いは自動で合わせます）
初めて読むトラックの待ち時間0.3 秒ほど1 秒ほど

つなぎ方

  • F11 の画面から: 「フロッピー」の欄の F（入れる／実機…）のメニューに、見つかった USB フロッピードライブ（「USB フロッピー A:（1.25MB 対応）」など）と Greaseweazle が出るので選びます。インストールアシスタント以外で使うときは、ディスクを入れ替えたら同じメニューの「読み直す」を選んでください。
  • INI で: FloppyDisk=FDD:A（Windows のフロッピードライブ A:。\\.\A: とも書けます）、FloppyDisk=GW（Greaseweazle を USB の ID で探します。見つからないときは GW:COM5 のようにポートを指定）。FloppyDisk= は FloppyImage= と同じ意味で、どちらで書いても構いません。
  • Greaseweazle の設定: GWDrive=A（PC のケーブルのドライブ A / B。Shugart 接続なら 0 / 1 / 2）、GWRevs=3（1 トラックを何回転ぶん読むか。1〜8。多いほど読みにくいディスクに強く、遅くなります）。
  • イメージとして残す: メニューの「今のディスクを D88 で保存」で、全トラックを読んで D88 に書き出せます（ID・CRC エラー・デリーテッドデータは残ります。読むたびに変わるセクタは 1 回分だけ）。次からはそのイメージを使えば本物のドライブが要りません。例: samples\slayers.INI（スレイヤーズ！のキーディスクを Greaseweazle で吸い出して使う）。
注意:
・USB フロッピーへの書き込みは、Windows からそのドライブを一時的に切り離せた（ボリュームをロックできた）ときだけ行います。できないときは書き込み禁止のディスクとして扱います。ドライブを開けないときは「管理者として実行」すると開ける場合があります。
・USB フロッピーで読めないセクタがあると、トラックごとに 2 回、セクタごとに 5 回まで、ヘッドを動かし直して読み直します。
・Greaseweazle は読み込みだけです。セーブを書き込むゲームは、先に D88 で保存してからそのイメージで遊んでください。

3-9. INI を書いて手動でインストールする

インストールアシスタントを使わずに、INI にフロッピーとインストーラを書いてインストールすることもできます。空のフォルダ（インストール先）に次のような PC98PLAYER.INI を置いて起動します。

; 「転送元のフロッピーのドライブ名を引数で渡し、今いるドライブへ写す」インストーラの例
[PC98PLAYER]
Drive=A
FloppyImage=SLAYERS_B.d88
FloppyDrive=B
Start=B:\INST.EXE
Args=B
CurrentDrive=A
ExitOnEnd=0
  • Start=B:\INSTALL.BAT のようにドライブ付きで書くと、そのドライブをカレントにして実行します。CurrentDrive= で別のドライブをカレントにもできます。
    「カレントドライブにインストールする」インストーラ（実機では A> から B:INSTALL と打って使うもの。同級生など）は、Start=B:\INSTALL.EXE と CurrentDrive=A（ゲームのフォルダ）を一緒に書きます。書かないとカレントがフロッピーになり、「カレントドライブがハードディスクドライブではありません」と止まります。
    説明書に「A:\NANPA を作り、そこをカレントにして実行」とあるもの（「カレントディレクトリーがルートディレクトリーです」と止まるもの）は、CurrentDirectory=A:\NANPA\ を書きます。フォルダはゲームのフォルダの下に自動で作られ、インストール先も NANPA フォルダになります。遊ぶときは Start=NANPA\NANPA.BAT とします。
  • フロッピーを A: にしないと動かないインストーラは、Drive=B・FloppyDrive=A のように入れ替えます。
  • インストーラが COMMAND.COM /C COPY … のように呼ぶ内部コマンド（COPY・MD・DEL など）にも対応しています。
  • インストールが終わったら、Start= などをゲームの起動用に書き換えます（FloppyImage= はキーディスクが要らなければ消します）。

フロッピードライブを 2 台使うインストーラ

「インストーラのディスクを 2 台目のドライブに、データのディスクを 1 台目のドライブに」のように、2 台のドライブを前提にしたインストーラは、 FloppyDisk2=・FloppyDrive2= で 2 台目にもディスクを入れます。例: ドライブ A: をハードディスク（インストール先）、B: を 1 台目、C: を 2 台目にする場合

[PC98PLAYER]
Drive=A
FloppyDrive=B
FloppyDisk=DN4_A.NFD     ; 1 台目（B:）: 最初に求められるデータのディスク
FloppyDrive2=C
FloppyDisk2=DN4_C.NFD    ; 2 台目（C:）: インストーラ（INSTALL.EXE）のあるディスク
Start=C:\INSTALL.EXE
Args=A:
FloppyWriteProtect=1     ; 「ライトプロテクト状態ではありません」と止まるインストーラ向け
ExitOnEnd=0
  • 「○ディスクをドライブ１に入れて下さい」と出たら、F11 の画面のフロッピーの欄で、操作するドライブ（D で切り替え）を 1 台目にして、N／P で求められたディスクにします。
  • ディスクの入れ替えを「いったん抜かれて、また入った」ことで確かめるインストーラもあるので、入れ替えた直後はディスク BIOS の SENSE に少しの間「準備ができていない」と答えます（実機でディスクを抜き差ししたときと同じ）。求められたディスクが最初から入っていて先へ進まないときは、同じディスクをもう一度入れ直してください。
  • 「フロッピーディスクがライトプロテクト状態ではありません」と止まるときは、FloppyWriteProtect=1 を書くと、入れるディスクがすべて書き込み禁止になります。1 枚ずつなら、F11 →「F: 入れる／実機…」のメニューの「書き込み禁止（ライトプロテクト）」で切り替えられます（入れ替えると、そのイメージの元の状態に戻ります）。
  • インストールが終わったら、Start= を作られた起動用のバッチ（例: DRA4\DRA4.BAT）に書き換え、FloppyDisk= などは消します。

3-10. キーディスク・プロテクトについて

PC98PLAYER のディスク BIOS（INT 1Bh）は、ID を指定したセクタの読み込み・READ ID・READ DIAGNOSTIC などに応え、イメージに記録されたセクタの ID・CRC エラー・デリーテッドデータ、 読むたびに内容が変わるセクタもそのまま返します。そのため、プロテクトの情報まで記録されたイメージ（D88・NFD r1 など）や Greaseweazle で読んだディスクなら、キーディスクの確認を通ることがあります。

  • FDI・ベタには特殊なセクタの情報が無いので、プロテクトつきのディスクの確認は通りません。
  • USB フロッピーは、Windows のドライバが特殊なセクタを扱えないため、確認を通りません。
  • インストール後、遊ぶたびにマスターディスクを求めるゲームは、第一章 1-7のとおり FloppyImage= にそのディスクのイメージ（または本物のドライブ）を書いておきます。
  • 確認で先へ進まないときは第四章 4-7を見てください。

3-11. フロッピーから直接起動するゲーム（ブートモード）

PC-98 が出たばかりのころのゲーム（PC-88 からの移植など）には、MS-DOS を使わず、電源を入れるとフロッピーの起動プログラム（IPL）から直接立ち上がるものが多くあります。 ハードディスクへのインストールも無く、ディスクの中身はファイルの形になっていないので、フォルダへ展開もできません。 PC98PLAYER は、こうしたディスクをブートモードで、実機と同じようにフロッピーから起動します。

ドロップディスクのイメージ（何枚でも）
→
判定MS-DOS のファイル表が無く、起動用のセクタがある
→
INIイメージのフォルダに自動で作る
→
起動1 台目のドライブから立ち上がる

始め方

  1. ゲームのディスクのイメージ（D88 など）を 1 つのフォルダにまとめます。
  2. 全部まとめて PC98PLAYER.EXE にドロップします。
  3. どのディスクにも MS-DOS のファイル表が無く、起動用のセクタを持つディスクがあれば、ブートモードで起動します（1 枚でも MS-DOS のディスクが混じっていれば、今までどおりインストールアシスタントになります）。
  4. 名前順で最初の起動ディスクが 1 台目のドライブに、残りの最初の 1 枚が 2 台目のドライブに入ります。
  5. イメージのフォルダに PC98PLAYER.INI（Boot=FD）を作るので、次からはそのフォルダに PC98PLAYER.EXE を置いてダブルクリックするか、ショートカットから起動できます。

ディスクの入れ替え（ドライブ 2 台）

ブートモードでは、実機と同じくフロッピードライブが 2 台あります。F11 の画面のフロッピーの欄で:

  • D（または見出しのボタン）で、操作するドライブを「ドライブ1」⇔「ドライブ2」と切り替えます。下の行に、もう一方のドライブに入っているディスクが出ます。
  • N／P で、そのドライブのディスクを、フォルダにあるイメージの中で次／前のものに入れ替えます。F で別のイメージや本物のドライブも選べます。
  • ゲームのセーブは、実機と同じくディスク（イメージファイル）へ書き込まれます。大事なイメージは先にコピーを取ってください。
  • ステートセーブは、2 台のドライブに入っていたディスクも覚えています。

INI の項目

項目説明
Boot=FDMS-DOS を使わず、1 台目のドライブのフロッピーから起動します。Start= は要りません。
FloppyDisk=1 台目のドライブに入れるディスク（起動ディスク）。
FloppyDisk2=2 台目のドライブに入れるディスク（FloppyImage2= と書いても同じ）。

当時のソフトは 8MHz・10MHz の機種で作られているので、自動で作る INI は CpuMHz=10・SoundBoard=26 にしてあります。速すぎるときや音が出ないときは変えてみてください（変えたら F11 → R で試せます）。

動かないもの

  • N88-BASIC を使うソフト: 本体の ROM に入っている N88-BASIC(86) で動くソフト（BASIC で書かれたゲームや、起動後に BASIC を呼ぶもの）は、PC98PLAYER には ROM が無いので動きません。 ROM の BASIC を呼び出したことを見つけると、「このソフトをプレイするにはPC98実機またはそのROMデータを搭載した仮想マシンが必要です」と表示して終わります。 例えば、アリスソフトの『ランス ―光をもとめて―』（配布フリー版）は、起動ディスクの読み込みのあと ROM の BASIC を呼ぶため、この表示になります。
  • FDC を直接操作するもの: ディスク BIOS（INT 1Bh）を使わず、フロッピーの制御装置を直接動かして読むソフト（プロテクトなど）は動きません。
  • BIOS の ROM を直接呼ぶもの: 割込みではなく ROM の中の番地を直接呼ぶソフトは、その旨を表示して止まります。
